## Handing back
Every time you stop, whether the work is done, blocked, or waiting on an answer, the message ends with what the user does next: the PR link with its live state, and the exact commands they are suggested to run, each in a fenced code block ready to paste (the suite to run, `tars pull` to apply, the server to restart, the login to complete). A pause with no next command and no link leaves the user guessing. Anything written for the user to run lives next to the work it acts on, in the repo or the directory they are working in, never in the session scratchpad; the scratchpad is only for files nobody but the agent will touch.
