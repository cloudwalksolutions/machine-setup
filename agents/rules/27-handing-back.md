## Handing back
Every time you stop, whether the work is done, blocked, or waiting on an answer, end with the PR link and its live state, plus any command the user would not know to run without you (the QA steps, `tars pull` to apply, a server to restart, a login to complete), each in a fenced code block ready to paste. Merging is the user's call and needs no prompting: never tell them to review or merge, and leave out `gh pr merge` and branch cleanup commands. When nothing needs running, the link is enough. Anything written for the user to run lives next to the work it acts on, in the repo or the directory they are working in, never in the session scratchpad; the scratchpad is only for files nobody but the agent will touch.
