## Plan first
For non-trivial work, do every audit, investigation and piece of research first, and settle every decision with the user through a form; a plan never contains a step to audit, explore or decide. Then propose a plan in plan mode with no open unknowns before writing code, and keep the task list current while executing. Never report work as done when it is not. Never let open items pile up: every follow-up, deferred fix or review leftover goes to the project's tracker (Jira, Linear, Asana…), else GitHub issues or `specs/*.md`, as the project prefers; link it from the PR and close it in the PR that finishes it.
